¿Qué son los condicionales?

Los condicionales expresan una condición y el resultado que depende de ella. En esta página veremos el Zero Conditional y el First Conditional.

🟢 Zero Conditional

Se utiliza para hablar de hechos generales, reglas, hábitos o situaciones que normalmente ocurren.

If + Present Simple, Present Simple

3 afirmativas

If I drink coffee at night, I stay awake.Si tomo café en la noche, permanezco despierto.
If I study English, I learn new words.Si estudio inglés, aprendo palabras nuevas.
If I exercise, I feel better.Si hago ejercicio, me siento mejor.

3 negativas

If I don't sleep well, I don't feel good.Si no duermo bien, no me siento bien.
If I don't study, I don't understand the lesson.Si no estudio, no entiendo la lección.
If I don't eat breakfast, I don't have much energy.Si no desayuno, no tengo mucha energía.

3 preguntas

What happens if I don't study?¿Qué pasa si no estudio?
Do I feel tired if I don't sleep well?¿Me siento cansado si no duermo bien?
What do I do if I have free time?¿Qué hago si tengo tiempo libre?

🔵 First Conditional

Se utiliza para situaciones futuras reales o posibles y el resultado que probablemente ocurrirá si se cumple la condición.

If + Present Simple, will + verbo en forma básica

3 afirmativas

If I study tonight, I will finish my homework.Si estudio esta noche, terminaré mi tarea.
If I practice English, I will improve my pronunciation.Si practico inglés, mejoraré mi pronunciación.
If I save money, I will buy something I need.Si ahorro dinero, compraré algo que necesito.

3 negativas

If I don't study, I won't pass the exam.Si no estudio, no aprobaré el examen.
If I don't finish my homework, I won't go out.Si no termino mi tarea, no saldré.
If I don't practice, I won't improve my English.Si no practico, no mejoraré mi inglés.

3 preguntas

What will I do if I finish my homework early?¿Qué haré si termino mi tarea temprano?
Will I study English if I have free time?¿Estudiaré inglés si tengo tiempo libre?
What will happen if I don't practice?¿Qué pasará si no practico?

📚 Diferencias principales

Zero ConditionalFirst Conditional
Hechos generales o situaciones habituales.Situaciones futuras reales o posibles.
If + present simple → present simpleIf + present simple → will + verbo
If I exercise, I feel better.If I exercise tomorrow, I will feel better.

Hello, my name is Keimer. Today I am going to explain the Zero Conditional and the First Conditional.

The Zero Conditional is used for general truths, habits and things that normally happen. Its structure is: if + present simple, present simple. For example: If I drink coffee at night, I stay awake.

The First Conditional is used for real or possible situations in the future. Its structure is: if + present simple, will + base verb. For example: If I study tonight, I will finish my homework.

These conditionals are useful in everyday life because they help us talk about what normally happens and what may happen in the future.
